# Crypto Signals Project
This project analyzes indicators like RSI, MFI, and MACD.

## Gold liquidity-sweep research (XAUUSD)

- [GOLD_LIQUIDITY_INDICATOR_SPEC.md](GOLD_LIQUIDITY_INDICATOR_SPEC.md): research findings and the full TradingView indicator spec (Arabic), ready to hand to Claude.
- `research/`: TradingView data, the reference engine (`sweep_engine.py`) and `run_study.py`, which reproduces every number (`pip install -r research/requirements.txt && python research/run_study.py`).
